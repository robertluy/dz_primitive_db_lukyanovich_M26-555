# Примитивная база данных

Учебный проект консольной базы данных на Python.
Текущий этап: подготовка пакета и настройка окружения, обработка команд.

## Установка

Требуются uv и Python 3.12 или выше.

```bash
uv sync
```

## Запуск

```bash
uv run database
```

## Проверка кода

```bash
uv run ruff check .
```

## Сборка

```bash
uv build
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.
Столбец `ID:int` автоматически добавляется первым.

Команды:

- `create_table <имя_таблицы> <столбец:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `help` — показать справку.
- `exit` — завершить работу.

Пример работы:

```text
create_table users name:str age:int is_active:bool
list_tables
drop_table users
exit
```

Имена таблиц и структура столбцов сохраняются в `db_meta.json`
в текущей рабочей папке и доступны при следующем запуске из неё.

## CRUD-операции

Данные каждой таблицы сохраняются в отдельном JSON-файле
в папке `data/`. Например, записи таблицы `users` хранятся
в `data/users.json`.

Файлы базы данных создаются в текущей рабочей папке.
Для доступа к сохранённым таблицам запускайте программу из той же папки.

Поддерживаемые команды:

- `insert into <таблица> values (<значение1>, ...)` — добавить запись.
- `select from <таблица>` — показать все записи.
- `select from <таблица> where <столбец> = <значение>` — отобрать записи.
- `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` — обновить записи.
- `delete from <таблица> where <столбец> = <значение>` — удалить записи.
- `info <таблица>` — показать структуру таблицы и количество записей.

При добавлении записи значение `ID` генерируется автоматически.
Передавать его в `insert` не нужно. Изменять `ID` через `update` нельзя.

Все остальные поля обязательны. Значения должны соответствовать
типам столбцов: `int`, `str`, `bool`.
Строки записываются в кавычках, логические значения — `true` или `false`.

Команда `update` поддерживает несколько присваиваний через запятую.
Условие `where` содержит одно сравнение на равенство.
Обновление и удаление применяются ко всем подходящим записям.

Пример полного цикла:

```text
create_table users name:str age:int is_active:bool
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29, is_active = false where ID = 1
select from users where ID = 1
info users
delete from users where ID = 1
info users
drop_table users
exit
```

## Декораторы и кэширование

Ошибки операций обрабатываются единым образом - программа выводит
сообщение и продолжает принимать команды.

Удаление записей и таблиц требует подтверждения.
Введите `y`, чтобы выполнить действие; другой ответ отменяет операцию.

Для `insert` и `select` отображается время выполнения в секундах.

Результаты одинаковых выборок сохраняются в кэше, реализованном
через замыкание. Операции изменения данных сбрасывают кэш.
Ключ выборки учитывает данные, условие и схему таблицы.
