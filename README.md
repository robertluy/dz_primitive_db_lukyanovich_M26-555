# Примитивная база данных

Учебный проект консольной базы данных на Python.
Текущий этап: подготовка пакета и настройка окружения.

## Установка

Требуются uv и Python 3.12 или выше.

```bash
uv sync
```

## Запуск

```bash
uv run project
```

## Проверка кода

```bash
uv run ruff check .
```

## Сборка

```bash
uv build
```
